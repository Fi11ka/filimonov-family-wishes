# Filimonov Family Wishes

Семейный Telegram Mini App для [@FilimonovFamilyWishes_bot](https://t.me/FilimonovFamilyWishes_bot). Русский интерфейс, персональные вишлисты, семья по коду, фотографии, цены, приоритеты и секретные бронирования.

**Состояние:** приложение реализовано локально. Production URL появится после подключения вашего Cloudflare, создания D1, добавления секрета бота и включения GitHub Pages. Наличие кода не означает, что приложение опубликовано.

## Использование без установки программ

Для публикации и использования приложения устанавливать Node.js на свой компьютер не нужно. Сборки, тесты и обновления выполняют GitHub Actions и Cloudflare Workers Builds. Пользователи открывают приложение в Telegram. Локальные команды ниже нужны только для необязательной разработки.

## Локальная разработка (необязательно)

Нужны Node.js 24 и pnpm 11.25.0. Установка pnpm: `npm install --global pnpm@11.25.0`.

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
pnpm dev
```

Откройте `http://127.0.0.1:5173/?demo=1` для демонстрации интерфейса. Демо не вызывает API и не сохраняет данные. Production API не содержит обхода Telegram-авторизации.

Для живого локального API: скопируйте `.dev.vars.example` в `.dev.vars`, укажите токен отдельного тестового бота, запустите `pnpm db:local`, затем `pnpm dev:api`. Vite использует `.env.local` с `VITE_API_URL=http://localhost:8787`. В локальном конфиге Worker задайте `APP_ORIGIN=http://127.0.0.1:5173` (не коммитьте это изменение). Telegram требует HTTPS: для проверки реального входа используйте опубликованный тестовый Worker и HTTPS-интерфейс. Не используйте поддельный initData для production.

## Размещение за 0 €

Подробная инструкция: [DEPLOY.md](DEPLOY.md). GitHub Pages размещает React/Vite, Cloudflare Workers обслуживает API, D1 хранит записи и небольшие сжатые фото. Не нужны VPS, платный домен, R2, сторонний auth или платные подписки. Нет процесса, который нужно держать запущенным, и нет искусственного keep-alive.

На Free действуют квоты. При превышении квоты сервис может временно не отвечать; абсолютную доступность и неограниченную нагрузку бесплатные провайдеры не гарантируют. Не включайте Workers Paid или автоматический переход на платный тариф. Текущие цифры и ссылки — в инструкции.

## Важные свойства

- Авторизация: HMAC-SHA256 Telegram `initData`, постоянное время сравнения, возраст до 1 часа, проверка полей и запрет дубликатов. ID берётся только из подписанного `user`.
- Один человек состоит в одной семье. Создатель может менять код и удалять участников; остальные могут выйти. Свой список доступен даже без семьи.
- API владельца и анонимного гостя не читает бронирования. В ответах отсутствуют статус, даритель, время брони, счётчики броней, reservation-dependent сортировка и ошибки редактирования.
- Брони: `PRIMARY KEY(gift_id)`, атомарный `INSERT … SELECT … ON CONFLICT`, проверка актуального доступа внутри записи; только создавший отменяет бронь.
- Гостевая ссылка: 256 бит случайности, в D1 только SHA-256, 30 дней, отзыв/замена, доступ к одному списку. Бронь требует Telegram-входа без вступления в семью.
- Анонимный просмотр сознательно не показывает бронь: иначе хозяин мог бы открыть свою гостевую ссылку и узнать статус. См. [SECURITY.md](SECURITY.md) о границах гарантии.
- До 100 желаний на пользователя. Фото сжимаются до 900 px, максимум около 160 КБ бинарных данных, отдельно загружаются по защищённому API. Оригиналы не сохраняются; HEIC зависит от декодера браузера, при ошибке нужен JPEG.
- Секрет бота — только Cloudflare Secret. Деплой API через Cloudflare Workers Builds, интерфейса — через GitHub Actions. Секреты в GitHub Actions не требуются.

## Файлы

| Путь | Назначение |
| --- | --- |
| `src/` | Адаптивный интерфейс, Telegram SDK, гостевой режим |
| `worker/index.ts` | API и серверное управление доступом |
| `worker/security.ts` | Проверка Telegram и валидация |
| `migrations/` | Версионированная схема D1 |
| `tests/api.test.ts` | Интеграционные тесты на настоящем локальном workerd/D1 |
| `.github/workflows/` | Проверки и публикация GitHub Pages |
| `scripts/` | Настройка, сборка API и проверка готовности публикации |

Для восстановления используйте D1 Time Travel или локальный защищённый экспорт. Экспорт базы содержит личные данные: не добавляйте его в репозиторий.

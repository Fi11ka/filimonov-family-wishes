# Сценарий 2. Бронирование подарка (друг в Telegram)

**Кто:** друг владельца или человек, открывший Telegram-ссылку на список (`s_…`). **Где:** «Друзья» → выбрать друга → карточка → «Подарю!».

## Сейчас

Бронь создаётся сразу по нажатию, без подтверждения (`main.tsx:282-303`). На сервере — атомарная запись с проверкой доступа (`worker/index.ts:746-794`). Владелец бронь не видит.

```mermaid
flowchart TD
    A["Открыть приложение"] --> B["Меню ☰ → «Друзья»<br/>на телефоне раздел спрятан в боковом меню"]
    B --> C{"Есть друзья?"}
    C -->|"Нет"| D["«Вместе мечтать ещё приятнее»<br/>→ «Добавить друга»"]
    C -->|"Да"| E["Сетка друзей + «Выберите друга»"]
    E --> F["Нажать на друга"]
    F --> G["Под сеткой загружается его список<br/>экран сам не прокручивается"]
    G --> H["Карточки в 2 колонки,<br/>кнопки 9 px"]
    H --> I{"Статус карточки"}
    I -->|"Свободно"| J["«Подарю!»"]
    I -->|"Занято другим"| K["«Уже выбрали» неактивна<br/>кто и когда — не показано"]
    I -->|"Моя бронь"| L["«✓ Отменить бронь»"]
    J --> M["Бронь сразу, без подтверждения"]

    N -->|"Желание в архиве / дружба удалена"| Q["Тост: «Список или подарок недоступен»"]
    O --> R["Список перезагружается,<br/>кнопка становится «Отменить бронь»"]
    P --> R
    Q --> R
    R --> S["Что дальше? Подсказки нет.<br/>Ссылка «В магазин» — мелкая"]:::dead
```

### Что работает хорошо

- Гонка двух дарителей исключена на уровне БД.
- Тайна брони соблюдена: владелец ничего не узнаёт из API.
- Отмена своей брони возможна даже после удаления из друзей.

## Предложение

```mermaid
flowchart TD
    A["Открыть приложение"] --> B["Нижняя навигация:<br/>Мой список · Близкие · Мои подарки"]
    B --> C["«Близкие»: крупные строки<br/>Имя · N желаний"]
    C --> D["Нажать на человека"]
    D --> E["Отдельный экран «Список Маши»<br/>кнопка «← Близкие» сверху"]
    E --> F["Карточки в 1 колонку на телефоне,<br/>кнопка «Подарю» во всю ширину"]
    F --> G["«Подарю»"]
    G --> H["Нижний лист подтверждения:<br/>фото, название, цена<br/>«Да, я подарю это» / «Отмена»"]
    H -->|"Отмена"| F
    H -->|"Да"| I{"Ответ API"}
    I -->|"Занято"| J["«Пока вы смотрели, этот подарок выбрал кто-то другой»<br/>→ «Посмотреть другие желания»"]
    J --> F
    I -->|"Ок"| K["Экран успеха:<br/>«Готово! Маша не узнает»<br/>«Открыть в магазине» · «Мои подарки»"]
    K --> L["«Мои подарки»: карточка с фото,<br/>для кого, ссылка, «Отменить»"]
```

**Ключевые изменения:**

- Подтверждение брони — один нижний лист с крупной кнопкой.
- Экран успеха вместо тоста: что произошло + следующий шаг.
- Список человека — отдельный экран с «Назад», а не блок под сеткой.
- «Мои подарки» = полноценные мини-карточки: имя получателя, фото, цена, «В магазин», «Отменить» (с подтверждением).
- «Убрать из близких» перенести в меню «⋯» на экране человека.

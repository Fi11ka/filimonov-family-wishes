# Автозаполнение по ссылкам: проверка и ограничения

Работает на существующем Worker, без дополнительных сервисов, подписок, секретов и миграций. Новое исправление подготовлено отдельным PR поверх main.

## Исправление фото на iPhone и Mac

Сбой воспроизведён в настоящем Safari на фото Amazon `B0C9TP6DD5`: файл успешно скачивался через API, но форма показывала «Фото слишком детальное». Причина — `canvas.toDataURL("image/webp")`: при отсутствии WebP-кодировщика браузер возвращает PNG, а изменение качества не уменьшает его размер. Поведение описано в [MDN](https://developer.mozilla.org/en-US/docs/Web/API/HTMLCanvasElement/toDataURL).

Теперь обработка проверяет фактический формат, пробует JPEG и при необходимости уменьшает размеры. Прозрачность перед JPEG заполняется белым. В API по-прежнему отправляется сама сжатая картинка, а не зависимая от магазина внешняя ссылка. Лимит 215 000 символов и проверка формата сохранены. Ошибка загрузки больше не скрывается за общей надписью: форма показывает конкретную причину.

После исправления в Safari проверены реальные фото Amazon и Wildberries: оба отображаются. Для этой проверки использованы настоящая форма, локальный Worker и отдельная тестовая D1 с вымышленным токеном; пользовательские данные Telegram не использовались. Это проверка браузерного этапа, а не публикация новой версии.

WB использует в card v4 поле `optionId`, более старый ответ — `chrtId`. Поддержаны оба формата. Если магазин прямо сообщает нулевой остаток, интерфейс объясняет отсутствие цены. Отсутствующая цена сама по себе не считается отсутствием товара.

Ozon и AliExpress могут требовать интерактивную проверку или вход. При такой блокировке фото можно загрузить файлом/из буфера, название и цену ввести вручную. Платные прокси, CAPTCHA-сервисы и обход защиты не подключены. Наличие парсера не означает, что магазин разрешает автоматическое чтение из Cloudflare.

## Остальное поведение

- Amazon: реклама удаляется из URL, сохраняется ASIN; цена берётся из основной области, исключены зачёркнутые цены и рекомендации.
- Ozon: `product_id` из поиска превращается в ссылку на товар. Цена по карте Ozon не подменяет общую цену.
- Wildberries: выбранный `size` сохраняется. Неизвестному варианту не присваивается цена другого размера.
- AliExpress: `sku_id` сохраняется, рекламный `spm` удаляется; доступную цену и вариант нужно проверить.
- Ответы, пришедшие позже ручного изменения поля или смены ссылки, не перезаписывают данные. Во время загрузки нельзя сохранить незавершённую форму.

Цены зависят от региона, времени, варианта и скидок. Обновление не делает мониторинг цен: автозаполнение выполняется при добавлении желания.

## Частичный импорт AliExpress из международной карточки

Новый PR добавляет только один запасной запрос к официальному `www.aliexpress.com`, когда `.ru` не отдал название или фото. Используется тот же ID товара и сохраняется `sku_id`; поиск похожего товара не выполняется. Проверяется, что после перенаправлений остались домен AliExpress.com и тот же `/item/ID.html`. Чужая карточка, главная страница и очередная защита отклоняются.

Из международной карточки берутся только название и фото. Её цена и доступность не переносятся: регион и вариант могут отличаться. Полученная с `.ru` цена сохраняется. Ссылка желания остаётся исходной российской. В форме источник обозначен «AliExpress (международный сайт)», название может быть на языке региона. Действующее предупреждение просит проверить вариант и цену.

Подтверждено реальным запросом из Cloudflare: международный сайт перенаправил на `pt.aliexpress.com/item/1005002333850679.html`, вернул название органайзера для кабелей и фото. Запасной сервис Jina Reader без ключа, проверенный отдельно, получил от Ozon 403, от AliExpress.ru 429; в приложение он не добавлен. Региональный Ozon.by тоже не отдал карточку (цепочка 307). Рабочий автоматический импорт Ozon этими проверками не найден.

Новые тесты проверяют тот же ID/SKU, сохранение исходной ссылки, отказ от иностранной цены, защиту от посторонних перенаправлений и отсутствие лишнего запроса при полной исходной карточке.

## Короткое русское название и подсказка близким (Workers AI)

Названия в магазинах длинные и часто на чужом языке: «Пехорка Пряжа для вязания Детская объёмная, микрофибра, черная», «KnitPro Nova Metal Deluxe Knitting Needle Tips Set 3.50 … 8mm». Теперь Worker переписывает такое название через [Cloudflare Workers AI](https://developers.cloudflare.com/workers-ai/): модель `@cf/meta/llama-3.3-70b-instruct-fp8-fast` возвращает JSON `{title, details}`.

- В поле «Название» попадает короткое название вещи на русском («Пряжа для вязания», «Набор спиц»).
- Бренд, модель, цвет, размеры и комплектация уходят в «Подсказку близким», но только если подсказка ещё пустая. Если модель не перечислила детали, туда целиком переносится исходное название, чтобы ничего не потерялось.
- Ответ модели проверяется: в названии должна быть кириллица, длина ограничена, управляющие символы удаляются. Если ответ странный, при ошибке, исчерпанной квоте или через 6 секунд без ответа остаётся исходное название магазина. Короткие русские названия («Тапочки») модель не получает.
- Привязка `AI` указана в `wrangler.jsonc`. Ни ключей, ни секретов, ни миграций не нужно. Бесплатно доступно 10 000 «нейронов» в день: одно название стоит примерно 25–40, то есть хватает на сотни добавлений. Если лимит исчерпан, просто остаётся исходное название.
- Модели передаётся только название товара и имя магазина, без данных пользователя.

Ozon, Яндекс Маркет и AliExpress.ru не пускают даже обычный браузер из-за пределов России, не говоря о серверах Cloudflare. Исправлением парсера это не решить. Возможные пути (ни один пока не подключён):

1. Официальные партнёрские API. Для AliExpress это AliExpress Affiliate API (`aliexpress.affiliate.productdetail.get`): название, фото и цена в выбранной валюте. Нужны регистрация в партнёрской программе, app key и secret. У Яндекс Маркета есть партнёрская программа с Content API, доступ выдают по заявке. У Ozon публичного API карточек для сторонних сайтов нет: Seller API работает только со своими товарами.
2. Небольшой сервер в России с браузером (Playwright), к которому Worker обращается за страницей товара. Его ставят на дешёвый VPS. Такие IP тоже иногда получают капчу, плюс надо следить за сервером.
3. Коммерческие сервисы парсинга с российскими прокси. Они платные, и их работа противоречит защите магазинов.

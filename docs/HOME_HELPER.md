# Домашний помощник: Ozon, DNS, Яндекс Маркет, AliExpress.ru

## Зачем он нужен

Ozon, DNS, Яндекс Маркет и AliExpress.ru не отдают страницы товаров серверам. Проверено 25 октября 2026 года:

| Откуда запрос | Ozon | DNS |
| --- | --- | --- |
| Cloudflare Worker (как сейчас) | бесконечные переадресации `?__rr=`, 403 | 401 (защита Qrator) |
| Yandex Cloud Functions, российский IP | бесконечные переадресации `?__rr=` с кукой `__Secure-ETC` | — |
| Сервис предпросмотров Microlink | 403, «Похоже, нет соединения» | 401 Qrator |
| Предпросмотр ссылки в Telegram | нет предпросмотра | нет предпросмотра |
| Обычный Chrome за границей | капча «Подтвердите, что вы не бот» | страница открывается |

Сайты пускают только настоящий браузер, причём Ozon — с российского адреса. Поэтому страницы открывает обычный Chrome на домашнем компьютере в России. Пользователи вишлиста ничего не устанавливают: они вставляют ссылку, как раньше.

## Как это работает

```
Пользователь вставляет ссылку Ozon
      ↓
Worker (Cloudflare) ставит задание в очередь (D1, хранится секунды)
      ↑↓  помощник сам спрашивает «есть задание?» раз в ~20 секунд
Помощник на домашнем компьютере → открывает страницу в Chrome →
отправляет короткую выжимку: заголовок, meta-теги, schema.org, данные цены
      ↓
Worker разбирает её теми же парсерами → форма: название, цена, фото
```

- Порты на роутере открывать не нужно: компьютер сам подключается к приложению по HTTPS.
- Помощник открывает только страницы Ozon, DNS, Яндекс Маркета, AliExpress.ru и картинки с их серверов. Любой другой адрес он отклоняет. Те же списки проверяет Worker.
- Помощник не передаёт куки, пароли и служебные токены браузера, только данные о товаре.
- Если компьютер выключен, Worker понимает это за секунду и показывает в форме: «помощник сейчас не в сети — добавьте фото и цену вручную».
- Для Amazon, Wildberries и остальных магазинов всё работает напрямую, как раньше.

Бесплатные лимиты Cloudflare не превышаются: помощник делает около 4 300 запросов в сутки при лимите 100 000, а каждый запрос использует не больше 35 из 50 разрешённых обращений к D1.

## Часть 1. Настройка приложения (владелец, один раз)

1. **Придумайте ключ помощника** — длинную случайную строку. На Mac или в Linux выполните в Терминале `openssl rand -hex 32`. Подойдёт и любой генератор паролей: не меньше 32 символов, латиница и цифры.
2. **Добавьте его в Cloudflare:** Workers & Pages → `filimonov-family-wishes-api` → Settings → Variables and Secrets → Add → тип **Secret**, имя `HELPER_TOKEN`, значение — ваш ключ → Deploy.
3. Миграция `0006_home_helper.sql` применяется автоматически при публикации из `main`.
4. Передайте родственнику **адрес Worker** (`https://filimonov-family-wishes-api.<поддомен>.workers.dev`) и **ключ**. Ключ передавайте лично или в отдельном сообщении. Если он утечёт, просто замените secret в Cloudflare и введите новый ключ на компьютере (`--setup`).

Проверка: `https://<адрес Worker>/api/helper/status` с заголовком `Authorization: Bearer <ключ>` возвращает `{"online":true}`, когда помощник работает. Без `HELPER_TOKEN` все адреса `/api/helper/*` отвечают 404, и вишлист работает как раньше.

## Часть 2. Установка на домашний компьютер в России

Нужен компьютер с Windows 10/11 или macOS, который почти всегда включён и подключён к интернету.

### 1. Установите программы

1. **Google Chrome** — https://www.google.com/chrome/. Если он уже есть, ничего делать не нужно. Подойдёт и Microsoft Edge, он есть в Windows по умолчанию.
2. **Node.js** — https://nodejs.org → большая кнопка **LTS** → установить с настройками по умолчанию.

### 2. Скачайте помощника

1. Откройте https://github.com/anastasiacopodevinho/filimonov-family-wishes → зелёная кнопка **Code** → **Download ZIP**.
2. Распакуйте архив и перенесите папку `helper` в удобное постоянное место, например в «Документы». Остальные файлы не нужны.

### 3. Первый запуск

- **Windows:** дважды щёлкните `windows-start.bat`.
- **Mac:** щёлкните `mac-start.command` правой кнопкой → «Открыть» → «Открыть». Так нужно сделать в первый раз, потому что файл скачан из интернета.

Первый запуск установит компоненты (около минуты) и спросит:

- **Адрес приложения** — адрес Worker от владельца.
- **Ключ помощника** — ключ от владельца.

Когда появится строка «Помощник работает», всё готово. Окно можно свернуть, но не закрывать.

### 4. Один раз откройте Ozon в окне помощника

У помощника свой профиль Chrome, отдельный от вашего. Чтобы Ozon сразу его «узнал»:

1. Закройте окно помощника.
2. **Windows:** откройте командную строку в папке `helper` (в адресной строке Проводника введите `cmd` и нажмите Enter) и выполните `windows-start.bat --show`.
   **Mac:** откройте Терминал, перетащите в него файл `mac-start.command`, допишите ` --show` и нажмите Enter.
3. Откроется Chrome с ozon.ru. Если Ozon попросит проверку, пройдите её. Можно полистать пару товаров. Входить в аккаунт Ozon не нужно.
4. Закройте окно и запустите помощника обычным способом, как в шаге 3.

Это же помогает, если в журнале помощника появилось сообщение «Магазин просит пройти проверку».

### 5. Автозапуск

- **Windows:** дважды щёлкните `windows-autostart.bat`. Помощник будет запускаться свёрнутым при входе в Windows.
- **Mac:** дважды щёлкните `mac-autostart.command`. Помощник будет работать в фоне и перезапускаться сам. Журнал пишется в `helper/helper.log`.

### 6. Чтобы компьютер не засыпал

- **Windows:** Параметры → Система → Питание → «Переводить в спящий режим» → **Никогда** (при питании от сети).
- **Mac:** Системные настройки → Аккумулятор (или «Экономия энергии») → «Не переводить в режим сна при выключенном дисплее» → вкл. Монитор можно выключать.

## Если что-то не работает

| Сообщение | Что делать |
| --- | --- |
| «Не найден Node.js» | Установите Node.js (шаг 1) и запустите снова. |
| «Приложение не приняло ключ» | Ключ неверный или его заменили. Запустите с `--setup` и введите заново. |
| «Нет связи с приложением» | Проверьте интернет. Помощник сам повторяет попытки. |
| «Магазин просит пройти проверку» | Шаг 4: запустите с `--show` и пройдите проверку. |
| В вишлисте «помощник не в сети» | Компьютер выключен, спит или окно помощника закрыто. |

## Что передаётся

- **Приложение → помощник:** адрес страницы товара одного из четырёх магазинов или адрес картинки с их сервера.
- **Помощник → приложение:** заголовок страницы, meta-теги (без csrf и других токенов), блоки schema.org, данные виджетов цены, названия и галереи Ozon, фрагменты скриптов с ценой (Яндекс Маркет, AliExpress) — до 400 КБ. Для картинки — сама картинка, до 1 МБ.
- В базе задание хранится, пока его ждут (до ~22 секунд), потом удаляется. Ежедневная очистка удаляет всё старше часа.

# Домашний помощник

Программа для компьютера в России, которая открывает страницы Ozon, DNS, Яндекс Маркета и AliExpress.ru в обычном Chrome и передаёт вишлисту название, цену и фото.

Установка по шагам: [docs/HOME_HELPER.md](../docs/HOME_HELPER.md).

Коротко:
1. Установите Google Chrome и Node.js (LTS) с https://nodejs.org.
2. Запустите `windows-start.bat` (Windows) или `mac-start.command` (Mac) и введите адрес приложения и ключ от владельца.
3. Включите автозапуск: `windows-autostart.bat` или `mac-autostart.command`.
